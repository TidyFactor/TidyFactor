### 🏛️ Core Principles

1. **Structure over Complexity:** Clean architectural contracts over monolithic sprawl.
2. **Evidence-First Quality:** Measure before optimizing; never claim improvements without DELTA benchmarks.
3. **Locked Tenant Isolation:** Database-level security boundaries (Postgres RLS) that never leak data.
4. **Deterministic Tooling:** Lightweight Python/Node CLI toolsets for verifiable execution.
